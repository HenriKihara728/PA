🏔️ O maior de três

Receba três números diferentes e diga qual deles é o maior. Bônus de interpretação: também vale mostrar se os números digitados foram iguais entre si.

O maior número é...
⚠️ Preciso de um empurrão?
  • Dica 1: trate os três como const a = Number(...), const b = ..., const c = ....
  • Dica 2: "acumular o maior": comece uma variável let maior = a; e vá trocando se b > maior. É o mesmo esquema que vocês usavam em C++.
  • Dica 3: para o bônus, um if com && checa se são iguais.
